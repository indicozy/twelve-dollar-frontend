# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind and assume good faith. Framework debates are welcome here, as long as they are about the code and
the numbers and not about the people. Harassment, insults and personal attacks are not.

## Reporting

If someone's behaviour in this project's issues, pull requests or discussions makes you uncomfortable, contact the
maintainer privately through the contact details on [the maintainer's GitHub profile](https://github.com/indicozy).
Reports are kept confidential. The maintainer may edit or remove comments, and block contributors who break this code.
